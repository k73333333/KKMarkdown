2. [ ] **整合 `MarkdownTextEditingController`**：
    - 改造现有的 `buildTextSpan` 方法。
    - 将现有的长图片占位符隔离逻辑（`WidgetSpan` 和隐藏 `TextSpan`）提取到最高优先级。
    - 对非图片占位符的普通文本区域，应用 `MarkdownHighlighter` 进行分词渲染。
3. [ ] **主题适配**：确保语法高亮（如代码块的背景色、关键字的颜色）能够随着全局明暗模式自动切换。
4. [ ] **性能验证**：测试在输入大量文本（包括复杂的代码块和标题）时，高亮计算不会引发卡顿或与现有的短 ID 图片渲染产生冲突。
